## Featured project

> [!IMPORTANT]
> Corp Active Directory Lab: a company network built from scratch
> 
> ![ad-lab-network-map.png](https://publish-01.obsidian.md/access/8e3c5ba1f351f32afc29093e35113de1/Featured%20project%20-%20Corp%20AD%20Lab/Images/ad-lab-network-map.png)
> 
> A fictional company, **Corp**, built end to end on my own 4-node Proxmox cluster: an isolated VLAN behind an OPNsense firewall, two Windows Server 2025 domain controllers, a file server, four department workstations and a **GLPI** help desk that staff log into with their AD accounts.
> 
> **Highlights**
> 
> - 802.1Q VLAN across a physical switch and Proxmox SDN, with firewall rules isolating Corp from the home network
> - AD DS, DNS, DHCP and an internal CA for **LDAPS**, replicated across two DCs
> - AGDLP file permissions, Group Policy, help desk delegation and **Windows LAPS**
> - GLPI on Debian (LAMP) with AD login and automatic asset inventory deployed by GPO
> - Every problem I hit is documented with its root cause and fix
> 
> `Proxmox VE` `VLANs` `OPNsense` `Windows Server 2025` `Active Directory` `Group Policy` `PowerShell` `PKI / LDAPS` `Debian` `GLPI`
